- **added** `simpson branch: N odd`: _basic_simpson(y, 0, N-2, ...): Simpson pairs over every interval. [7.1]
- **added** `simpson branch: N even, N >= 4`: _basic_simpson(y, 0, N-3, ...) plus Cartwright's last-interval segment alpha*y[-1] + beta*y[-2] - eta*y[-3]. [7.1; A11]

- **added** `integral_from_zero(f, k0, step, e0, axis=-1)`: The oriented integral from 0 V to every sample of f along axis, same shape as f, float32. [7.2; B11; 2; 9]
- **added** `integral_from_zero branch: no sample at 0 V (e0 != 0.0)`: Stencil f-2, f-1, f1, f2 = f[k0-1], f[k0], f[k0+1], f[k0+2]; [7.2; B11]
